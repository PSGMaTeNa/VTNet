# Contributing to VTNet

We are excited that you want to contribute! To protect both you and the project's ecosystem, we require all contributors to accept our **Contributor License Agreement (CLA)** before their first pull request can be merged.

## How to Accept the CLA

We use an automated system to manage CLAs:
1. Open your Pull Request (PR) as usual.
2. A CLA bot will automatically check your GitHub username.
3. If you haven't signed the CLA yet, the bot will leave a comment on your PR with instructions.
4. You can accept the agreement simply by replying to the PR with the exact phrase requested by the bot (e.g., `I hereby accept the CLA`).

You can read the full legal text in our [CLA.md](CLA.md).
